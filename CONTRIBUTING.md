# Contribuir

Este repositório é o **sítio do jogador**: instruções, imagens e os instaladores nas
[Releases](https://github.com/frederico-kluser/cyberpunk2077-mods-public/releases). O código-fonte do mod
vive num repositório privado.

## Encontraste um problema?

Abre uma [issue](https://github.com/frederico-kluser/cyberpunk2077-mods-public/issues/new/choose) com:

1. a **versão do mod** (aparece no nome do zip) e a **versão do jogo**;
2. o que fizeste e o que esperavas;
3. a saída do instalador ou o ficheiro `bin/x64/plugins/cyber_engine_tweaks/scripting.log`
   (as linhas com o nome do mod);
4. o teu sistema (Windows 10/11, Linux, Steam Deck) e o launcher (Steam, GOG, Epic).

## Queres sugerir algo?

Abre uma issue de *feature request*. Ideias sobre o site do Replay Center, categorias de reset ou
mensagens de erro são bem-vindas — o que muda o motor ou a tabela de missões passa pelo repositório
privado.

## Pull requests

Não se aplica: o código não está aqui. Um PR com correções de **texto das instruções** é aceite — abre
uma issue primeiro para combinarmos.

## Código de conduta

Este projeto segue o [Contributor Covenant](CODE_OF_CONDUCT.md).
